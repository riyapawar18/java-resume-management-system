# Java Resume Management System

A dynamic resume management web application built using Java Spring Boot, MySQL, JPA/Hibernate and Thymeleaf.

## Features

- Dynamic resume
- Admin login
- Skill management
- Project management
- Create, Read, Update and Delete operations
- REST APIs
- MySQL database
- Spring Security authentication
- Thymeleaf frontend

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- HTML
- CSS
- REST API
- Maven
- Git
- GitHub

## API Endpoints

### Skills

GET /api/skills

GET /api/skills/{id}

POST /api/skills

PUT /api/skills/{id}

DELETE /api/skills/{id}

### Projects

GET /api/projects

GET /api/projects/{id}

POST /api/projects

PUT /api/projects/{id}

DELETE /api/projects/{id}

## Run Locally

Clone the repository.

Configure MySQL.

Update database credentials.

Run:

mvn spring-boot:run

Open:

http://localhost:8080/
